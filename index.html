Wire it in fifteen lines

Plug a durable runtime under your ADK agent. The agent code does not change.

treasury/app.py treasury/main.go treasury/app.ts treasury/App.java 
# wire a durable runtime under an ADK agent
import tape
from tape.adk import durable_app

app, runner = durable_app(
    name="treasury",
    agent=root_agent,                            # your ADK LlmAgent
    budget=tape.Budget(usd_cap=50, token_cap=2_000_000),
)

# mark non-idempotent tools — the outbox owns dispatch
@tape.outbox_tool(business_key=lambda a: a["id"])
def wire_transfer(args): ...
import (
    "context"
    tape "github.com/vamsiramakrishnan/durable-agents/tape/sdk/go"
)

d, _ := tape.NewDurableApp(ctx, tape.DurableConfig{
    Name:   "treasury",
    Budget: tape.Budget{USDCap: 50, TokenCap: 2_000_000},
})
defer d.Close()

// register a non-idempotent tool via the outbox
d.OutboxTool("wire_transfer", transfer, tape.OutboxOpts{
    BusinessKey: func(a Args) string { return a.ID },
})
import { durableApp, outboxTool } from 'tape-ts';

const app = durableApp({
  name:   'treasury',
  budget: { usdCap: 50, tokenCap: 2_000_000 },
});

// mark non-idempotent tools — the outbox owns dispatch
const wireTransfer = outboxTool('wire_transfer', transfer, {
  businessKey: (a) => a.id,
});
import dev.tape.DurableApp;

try (DurableApp app = DurableApp.wire(new DurableApp.Config()
        .name("treasury")
        .budget(new DurableApp.Budget(50.0, 2_000_000)))) {

    // app.client() is the journalled gRPC client
    app.outboxTool("wire_transfer", transfer,
        cfg -> cfg.businessKey(a -> a.getId()));
}

Tool bodies stay plain. The safety contract — business_key, status_check, compensate — is enforced at construction and on the wire, so blind retry on a wire transfer is structurally impossible.

The model, in one breath

One append-only WAL. Three semantic projections.

Source of truth WAL Append-only. Per-run. What happened.
Projection Decisions Memory of reasoning. Replayed on resume.
Projection Effects Memory of reality. Confirmed effects are skipped.
Projection Obligations Memory of responsibility. Reactors close the gap.

Tape is not checkpointing Python. Tape is: record every model decision · record every external effect intent & result · replay decisions on resume · skip confirmed effects · stop on ambiguity · reconcile reality · compensate when reality disagrees.

What you get

Crash-survival

Every decision and effect is journaled. A crashed run reconstructs and continues. Confirmed effects are not re-executed.

Non-idempotent safety

Three commands to production

From a clean clone to a deployed agent on Cloud Run.

bash 
# 1. Install — one command bootstraps every toolchain, builds, and wires the SDKs
./setup.sh

# 2. Scaffold and run locally — server + reactors + agent on sqlite
tape init treasury
cd treasury && tape dev

# 3. Render & apply Terraform on GCP, then deploy
tape provision gcp --apply
tape deploy gcp --target cloud-run

Verify the environment any time with make doctor. The full ten-minute walk-through is in the quickstart.
